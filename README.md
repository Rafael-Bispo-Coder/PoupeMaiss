# PoupeMaiss 💰

Aplicativo mobile de controle financeiro pessoal em PT-BR, com foco em poupar mais a cada mês.

## Stack

- **React Native + Expo** (Android/iOS)
- **TypeScript**
- **expo-sqlite** — persistência local
- **React Navigation** — navegação (tabs + stack)
- **Lottie** — animações
- **AsyncStorage** — onboarding

## Requisitos

- Node.js >= 18
- npm >= 9
- Expo Go app (no celular) ou emulador Android/iOS

## Instalação

```bash
git clone https://github.com/Rafael-Bispo-Coder/PoupeMaiss.git
cd PoupeMaiss
npm install
```

## Como rodar

```bash
npm start
```

## Testes

```bash
npm test
```

## Funcionalidades

- 📋 Dashboard: resumo mensal, progresso de metas, ações rápidas
- 💳 Transações: listagem com filtros, exclusão
- ➕ Nova Transação: receita/despesa com categoria
- 🎯 Metas: criação e acompanhamento de metas
- ⚙️ Configurações: reset de dados
- 🎬 Onboarding com animação Lottie
